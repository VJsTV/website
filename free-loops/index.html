How do I use these in Resolume? +

Import the ZIP into Resolume Arena or Avenue via File → Add Files to Library. The clips appear in your Media Library panel and can be dragged onto any clip slot. They are all loop-ready — just set the clip to loop mode in the clip settings panel.

How do I use these in TouchDesigner? +

In TouchDesigner, use a Movie File In TOP and point it at any clip from the pack. Set the Play Mode to Loop and the clip will cycle seamlessly. For multi-clip setups, use a Switch TOP driven by a Count CHOP or MIDI input to cut between clips in real time.
